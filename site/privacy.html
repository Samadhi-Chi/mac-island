应用与网站具有不同的数据边界。下面分别说明，避免把“本机应用”误解为“访问网站也没有服务器记录”。

应用读取什么

Mac Island 从受支持客户端的本机 Hooks、观察接口、日志或数据库读取会话状态。原生标题、对话和进度详情可在内存中用于展示。Muse / Grok Bot 的实验来源仅在显式启用并授权后读取已验证界面中的有限元数据。

应用不代发消息、不代做审批、不启动代理任务。当前产品策略禁用遥测、自动更新和远程 SSH 服务；用户点击外部链接或打开客户端，会交给 macOS 和相应应用处理。

连接与调试

只读产品禁用 Cursor 账号令牌读取和直接联网查询额度。Codex 使用 Island 自己启动的观察进程的私有管道。Bridge 调试日志默认关闭，启用后也不记录正文、路径或会话 ID；Bridge 会按关闭或保留期策略清理可识别的自有日志；旧逐会话统计、未知文件和旧自定义目录中的平铺日志仍需手动删除。

屏幕上显示什么

  • 只显示状态：客户端与通用状态；隐藏原生标题、Bot 名称、正文、路径与会话 ID。
  • 显示标题：增加原生会话标题或 Bot 名称；仍不显示正文、活动标签、路径或 ID。
  • 显示详情：显示可读的本机进度；完整路径与原生 ID 位于明确打开的详情中。

新安装默认显示标题；已有安装迁移时保留原先的详情方式。临时隐藏只影响 Island，恢复时回到原选择；不遮挡其他应用，不停止底层读取。

本机保留与删除

最近记录默认保留路由元数据 7 天、最多 200 条。可改为 24 小时 / 100 条、仅本次运行或关闭。它包括客户端、工作目录、原生会话 ID 与活动时间，不包含对话正文、提示词、回复或派生标题。

清空最近记录不删除客户端历史，也不会一并清空独立的会话关联或额度缓存。旧版本留下的诊断文件不会被新版自动删除；系统备份、交换空间与客户端自身存储不受 Mac Island 控制。

权限与诊断

实验来源的辅助功能权限由你主动授予，可以在系统设置中撤回。安装 Hooks / 插件是显式操作，使用本机备份与原子写入。开发构建不代表你已授权安装或修改客户端配置。

主动导出的诊断摘要只包含版本、固定连接状态和故障分类，不复制客户端配置、日志、项目路径、会话标题、对话或凭据。导出的文件留在本机，不自动发送；分享前仍应自行检查。

这个网站

本网站由 GitHub Pages 托管，页面使用本地静态资源；没有我们添加的分析脚本、广告、Cookie 或浏览器本地存储，也不读取你的客户端或会话。

GitHub 作为托管服务会为安全目的记录访问者 IP 地址。点击 GitHub、Apple 或上游链接后，适用目标服务自己的隐私规则。参见 GitHub Pages 数据说明与 GitHub 隐私声明。

反馈与隐私问题

普通问题可按支持页面反馈。公开 Issue 不适合提交真实会话、截图中的私人信息、密钥或完整诊断日志。安全问题请先查看仓库 Security Policy 中的私密报告说明。
