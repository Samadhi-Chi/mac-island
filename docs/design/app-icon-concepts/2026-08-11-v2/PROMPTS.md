# Mac Island · Final Prompt Set

以下为本轮 5 个方向的可复现提示词整理。共同约束：原创方形 App Icon；无文字、字母、Apple 标志、设备样机、四宫格、波形、人物或外层圆角方形容器；构图居中并保证小尺寸可读。

## 01 · Notch Pulse

为本地 macOS AI 编码会话监控工具 Mac Island 设计原创图标。用一个连续、粗壮的哑黑横向胶囊作为岛体，在上缘中央切出一个温暖珊瑚色的单一状态脉冲负形。瑞士式极简矢量语言，象牙白背景，石墨黑与珊瑚色，强轮廓、大留白、无装饰，32 px 仍清楚。

## 02 · Command Key

将 Mac Island 表达为一个无任何字符的石墨色实体控制键：厚实圆角方形键帽，中央仅有一道内凹的琥珀色横向状态槽。工业产品摄影式 3D，触感表面、柔和阴影、冷灰背景，成熟、安静、可信，避免键盘符号和通用快捷键联想。

## 03 · Agent Relay

用一条连续的粗蓝色路径穿过三个大型胶囊节点，最终汇入中央横向状态岛；节点分别使用钴蓝、水青和珊瑚色。扁平几何系统图语言，深海军蓝背景，只有大形状，不出现细线、网络网格或数据文字，体现多个 AI 会话被统一汇总。

## 04 · Intervention Tab

正视构图：一个宽大的哑黑横向胶囊，在中心精确升起一片透明烟灰玻璃标签，标签内只有一个温暖橙色圆点。建筑式、克制的空间玻璃材质，冷灰背景，强轮廓，32 px 可读。禁止头盔、面具、蝴蝶结、翅膀、衣物、自由曲线和交通灯。

## 05 · Night Beacon

在深海军蓝背景上，用一个低矮的黑色抽象岛体承托一段月金色信标弧线，弧线末端只有一个钴蓝小点。编辑插画式极简，大色块、大留白、安静夜间氛围；不要画真实灯塔、海浪、星空或地平线。
