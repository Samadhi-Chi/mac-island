Mac Island observes local activity. Your clients execute the tasks; you decide when to view and act.

Getting started

  1. Developers can build the repository using Xcode 26+ and Swift 6.2+. Open PingIsland.xcodeproj and select MacIsland. Follow the repository README for the build and test commands.
  2. The first-run guide introduces the top-of-screen and floating surfaces, connections and existing connection health.
  3. Install supported hooks or plugins explicitly in Integrations. Onboarding does not install integrations, request Accessibility permission or start a task.
  4. Try the separate monitor demonstration. Its synthetic examples do not enter real sessions or recent records.

Current development validation primarily uses Apple Silicon. A macOS 14 deployment target is not evidence of minimum-OS or Intel hardware acceptance.

Current sessions and recent records

Current sessions show observable sessions and prefer native client titles. Unavailable titles are identified as such; folders and conversation text are not substituted for titles.

Recent records contain local routing metadata, not a backup of chat history. Clearing them does not delete history in the original client.

Click a row to select it. An explicit open action or Enter requests navigation. Feedback distinguishes a located terminal, a sent request, opening only the app, and failure. macOS accepting a link does not confirm that the correct conversation is visible.

CLI continuation currently offers a preview and command copy. One-click execution is not certified. Replies, approvals and task execution remain in the original client.

Muse, Grok Bot and Dot

Muse 4.1 / 6.0 and Grok Bot 0.68.1 are experimental current-interface sources, disabled by default. Enable each source explicitly and grant Accessibility permission yourself.

  • One card represents a currently identifiable Bot context. Multiple activities inside a card do not become multiple sessions.
  • Muse 6.0 reads names only from its verified English layout. Muse 4.1 Activity entries can appear inside the Bot card.
  • Background discovery, accurate execution state and conversation recovery are not guaranteed. Unknown activity is excluded from running counts and recent records.
  • Unknown versions, missing permission or unreadable interfaces produce an explicit status and stop the affected read.
  • Dot has an app entry only; an independent task source has not been verified. Ordinary Codex sessions remain labeled Codex.

Connection troubleshooting

First check that only one Mac Island instance is running. Review connection health and the last successful read in Integrations. An empty list can mean there is no active session. Check the source, version and permission before reinstalling plugins.

Telemetry, automatic updates, remote SSH services and paid unlocking are not enabled. Development checks do not replace installation, permission migration, multi-display, sleep/wake and long-duration acceptance.
