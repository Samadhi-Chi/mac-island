# Cursor 像素图标概念稿

C 方案已获确认并接入 Mac Island。应用内只渲染中心晶体，不显示 GIF 预览中的黑色方框底板。

共同约束：

- 32×32 逻辑像素画布，硬边、无抗锯齿；接入时映射到 18–30pt。
- 黑色阶梯圆角底板，四档中性银灰棱面；主体是重新绘制的 17×17 像素四面晶体，不复制 Cursor 官方图标位图。
- 动效只改变几何体本身，不增加光环、轨迹、粒子或悬浮装饰。
- 32 帧、约 1.76 秒循环；空闲态可降至静帧，工作态连续播放。

## A — Facet Orbit（推荐）

轮廓完全固定，四个银灰棱面的高光顺时针流动。辨识度稳定，长时间运行最不打扰，也最适合和 Codex 的蓝色旋转方块形成差异。

## B — Prism Tilt

几何体在 76%–100% 宽度之间缓慢倾转，高光集中到右侧棱面。动效比 A 明显，但不会缩成一条线；适合希望一眼看出“正在运行”的场景。

## C — Aperture Pulse

四个棱面以 1px 开合，中心保留纯黑留缝，不显示核心光点。像素感最强，节奏清楚；视觉性格比 A 更活泼。

建议先在 A 与 C 中选择：A 更精致耐看，C 更有“正在执行”的反馈感。
