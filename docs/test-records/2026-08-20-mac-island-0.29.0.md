## 结论

Mac Island 设置页已按原生 macOS 设置窗口重构，并完成真实安装版视觉验收。
窗口使用系统标题栏与交通灯、全高材质侧边栏、系统搜索框、单一强调色选中态、
语义标签颜色和自适应分组卡片；不再强制暗色，也不绘制假的窗口控件。

实现遵循 Apple Human Interface Guidelines 的 Materials、Sidebars、Color 与
Settings 指南：使用系统材质和语义颜色适配浅色/深色外观，用侧边栏承载顶层
设置分类，并保留 `Command-,` 打开设置的标准 macOS 行为。

## 视觉与交互验收

- 标准红黄绿交通灯位于真实标题栏，不是 SwiftUI 仿制按钮。
- 左侧侧边栏延伸至标题栏下方，搜索框、彩色分类图标与系统蓝选中态均使用
  AppKit/SwiftUI 语义颜色。
- 右侧使用居中的分类图标、标题和说明卡片；设置项使用系统背景上的浅层分组卡片、
  语义分隔线、原生 Toggle、Picker 与 Button。
- 浅色模式实机截图与用户提供的“系统设置”参考进行了逐项对照；正文、次级文字、
  边栏材质和卡片层级没有写死为纯黑或纯白。
- 搜索、键盘上下移动、侧边栏选中与 `Command-,` 打开设置均保留。
- SwiftUI `Settings` scene 与自定义设置窗口控制器使用同一套窗口配置，避免入口不同
  导致两套视觉。
