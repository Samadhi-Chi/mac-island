使用指南

先看状态，
再回到工作。

Mac Island 是本机观察工具。客户端负责执行任务，你决定何时查看和操作。

目前是开发预览，尚无正式签名安装包。不要使用上游 Ping Island 安装包代替本项目，也不建议通过关闭 Gatekeeper 或移除隔离属性来安装开发产物。
开始使用会话列表客户端接入实验来源版本与限制

开始使用

  1. 开发者可从本仓库构建。使用 Xcode 26+ / Swift 6.2+，打开 PingIsland.xcodeproj，选择 MacIsland；完整构建步骤见仓库 README。
  2. 首次引导选择屏幕顶部或悬浮 Island，了解客户端接入方式，再查看已有连接状态。
  3. 在集成设置中按需安装支持的 Hooks 或插件。引导不会自动安装集成、申请辅助功能权限或发送任务。
  4. 可以先体验独立监控演示。演示是合成数据，不进入真实会话与最近记录。

本轮主要开发验证在 Apple Silicon 上进行。macOS 14+ 是部署目标，不代表最低系统与 Intel 已完成实机验收。

当前会话与最近记录

当前会话展示当前可观察的会话。标题优先使用客户端的原生名称，无法读取时明确提示，不拿项目目录或对话正文代替。

最近记录是本机保存的路由元数据，不是聊天历史备份。清空它不会删除客户端历史。

点击一行用于选择；明确的打开按钮或 Enter 才执行导航。反馈会区分“已定位终端”“请求已发送”“只打开应用”与失败。打开链接被系统接受，不等于已确认正确会话显示。

CLI 续接目前仅提供预览与命令复制，尚未认证一键执行。回复、审批与任务执行始终留在原客户端。

客户端接入方式

客户端当前来源使用边界
Codex本机观察连接、可选 Hooks依赖受支持的客户端可执行文件与协议；重连只重连 Island 的观察连接。
Cursor本机数据库只读观察数据库结构变化可能影响识别，不修改客户端记录。
Claude CodeCLI / Desktop Code Hooks需要显式安装集成，审批仍在原客户端。
OpenCode / Hermes官方事件插件及有限元数据恢复按需安装；来源或数据库结构未知时停止相应恢复。
DeepSeek HarnessDSH CLI / 本机 Web UI 的官方实时事件需要对应插件与配置。

这些是当前代码的接入边界，不是对所有客户端版本的兼容承诺。

Muse、Grok Bot 与 Dot

Muse 4.1 / 6.0 与 Grok Bot 0.68.1 是默认关闭的实验性当前界面观察，需要分别启用来源，并主动授予辅助功能权限。

  • 每个当前可识别 Bot 上下文显示一张卡。不会因为一张卡内有多个活动，就算成多个会话。
  • Muse 6.0 当前只读取已验证英文布局中的名称；Muse 4.1 的 Activity 可收在 Bot 卡片内。
  • 不保证发现所有后台 Bot、准确运行状态或恢复聊天。未知状态不计入运行数，也不进入最近记录。
  • 版本未知、权限不足或界面不可读时，显示原因并停止对应读取。
  • Dot 目前只有应用入口，未验证独立任务来源。普通 Codex 会话仍按 Codex 显示。

遇到连接问题

先确认只运行一份 Mac Island，再查看集成设置中的连接状态与最近成功读取。空列表可能只是没有活动会话。不要反复安装插件来代替检查来源、版本和权限。

当前不启用遥测、自动更新、远程 SSH 服务或收费解锁。已完成的开发检查不代替真实安装、权限迁移、多屏、睡眠恢复与长时间运行验收。
