# Mac Island 使用帮助

## 开始使用

首次引导依次说明展示位置、连接客户端和连接状态；可从“重新体验首次引导”再次打开。先选择停靠在屏幕顶部，或使用可移动的悬浮模式。将鼠标移到 Island 上，或点击展开，即可查看当前会话。没有会话时，先在受支持客户端中打开或开始一个任务，再检查 Mac Island 的集成设置。

在集成设置中只启用你需要的客户端。检测连接不会替你安装配置；安装、更新、回滚和卸载集成都需要明确操作。安装时会备份受影响配置。不要同时运行应用程序文件夹和构建目录里的多个 Mac Island 副本。

## 当前会话与最近记录

“当前会话”展示现在已观察到的来源，标题使用客户端原生名称；名称暂时不可用时会明确提示，项目目录不是替代标题。“最近记录”展示已观察过、当前未显示的会话路由信息，不是完整聊天历史。

选择行用于查看；点击“在客户端打开”等明确按钮，才会请求导航。应用会区分已定位终端、已发送打开请求、仅打开应用和失败。系统接受打开请求不代表已经确认正确会话出现在屏幕上。

有些命令行会话可以查看续接预览并复制命令。本版本未认证一键 CLI 续接；复制前请检查目标目录和会话，实际执行由你决定。

## 内容显示与静音

应用保持静音。任务状态变化可以更新收起指示，但不会自动展开详细内容；悬停或点击后才显示详情。

内容显示提供三个选项：“只显示状态”隐藏会话标题、Bot 名称、正文和路径；“显示标题”保留原生标题、客户端和通用状态，隐藏正文、活动标签、路径和会话 ID；“显示详情”展示本机可读详情。新安装默认显示标题，已有版本保留原先的详情偏好。

会议或投屏前可点击“临时隐藏内容”，临时切换到只显示状态；“恢复显示”返回你原来的选择。临时隐藏仅影响本次运行，不修改原客户端，也不等于停止监控。

## 需要关注的任务

Island 可以提示某个任务需要关注，但不会代做审批、回答问题或发送消息。请通过返回客户端的操作，到原客户端完成这些步骤。“查看监控演示”会在独立窗口展示运行、待关注和完成，可切换顶部 Island 与悬浮 Island 的预览；演示使用明确标记的模拟数据，不查询真实会话，也不写入最近记录。

## Muse、Grok Bot 与 Dot

Muse 和 Grok Bot 需分别启用，并由你授予 macOS 辅助功能权限。它们属于实验性当前界面观察，只支持已适配版本和布局。

每个已识别的当前 Bot 上下文显示一张卡；Activity 不会拆成多个会话。Muse 6.0 当前只观察名称；Muse 4.1 的原生活动可收在同一 Bot 卡内。未知运行状态不会算作“运行中”。这不能替代全部后台 Bot 的发现、准确任务状态或聊天恢复。

权限不足、应用未运行、版本不支持或当前界面不可读时，来源卡会说明原因。点击打开应用只会打开该应用，不保证切换到具体 Bot。Dot 目前只有应用入口，普通 Codex 会话仍按 Codex 显示。

## 看不到会话时

1. 确认只运行一份 Mac Island，并且客户端确实已打开目标任务。
2. 查看集成设置中的连接状态和最近成功读取。没有新事件本身不代表连接断开。
3. 若 Codex 连接失败，可使用重连操作；它只重连 Island 自己的观察连接，不会重启 Codex。
4. 对需要 Hooks 的来源，先检查集成，再按提示主动安装或更新。对 Muse/Grok Bot，检查来源开关、受支持版本、当前界面和系统授权。
5. 若仍有问题，记下应用版本、客户端版本和来源卡的状态；必要时主动导出诊断，检查后再分享。

## 记录与退出

设置中可以调整最近记录的保留时间或清空最近记录。清空不删除客户端历史，也不清空所有 Island 缓存；详见离线隐私说明。

退出 Mac Island 会停止本应用的观察，不会停止其他客户端的任务。删除应用前，可先在集成设置中卸载已安装的 Hooks。系统权限可在 macOS 系统设置中撤销。

## 版本与支持

“关于”显示当前版本，并提供离线隐私说明及第三方许可。本版本不自动检查更新。如“关于”中显示本产品的官网或支持入口，可使用该入口；若未显示，请通过取得安装包的可信渠道查询发行者联系方式。不要把上游 Ping Island 的下载或问题入口当作本产品的更新和支持入口。
