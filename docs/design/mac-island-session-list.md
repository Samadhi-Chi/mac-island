# Mac Island 会话列表

2026-10-07，跟踪 [#25](https://github.com/Samadhi-Chi/mac-island-private-archive/issues/25)。

## 信息与入口

列表默认直接显示「当前会话」和数量，右侧「最近记录」是次级入口。
最近记录提供「返回当前会话」按钮。没有第三个空白页面，也不再把
`Session list` 作为分段选择器的可见标签。

当前会话仍按既有状态、30 分钟活动窗口、本地隐藏和子会话规则展示。
最近记录只展示当前列表以外、曾在本机观察过的会话；过滤仅影响显示，
不删除索引中的记录，不按目录合并不同会话。保留策略仍是默认 7 天 / 200 条，
可在设置中切换为 24 小时 / 100 条、仅本次运行或关闭。

行的主标题使用客户端原生名称。目录是带有「目录」标签的次级信息，
不能冒充会话名称。标题缺失或读取失败时显示「标题暂不可用」。
完整路径、原生 ID、来源和客户端信息位于 `⋯` →「会话详情…」。
当前列表保留状态形象、活动详情和模型信息；详情仍由悬停/选择打开。

## 原生标题与隐私

`SessionListPresentation` 以客户端、来源和原生 ID 对应观察记录。
`SessionListTitleStore` 在内存中共用当前/最近行的原生名称，默认先展示
观察到的名称，打开列表时通过现有 Codex 连接读取更新。

Codex 使用 `thread/read` 的 `thread.name`，明确传入 `includeTurns: false`。
[官方协议](https://learn.chatgpt.com/docs/app-server) 说明 `name` 是用户界面的
线程名称，`thread/read` 不续接或加载线程。此处的窄接口不启动观察进程，
不调用 `SessionStore` 导入历史，不读取对话 turns，避免查询标题使旧记录
重新进入当前列表。`preview`、摘要、第一条消息和目录均不作为标题回退。

每批最多四个并行读取，30 秒内复用结果；列表关闭后停止请求。
取消或被替代的查询不能发布旧结果，观察到的新名称优先于较早的读取。
锁屏/睡眠遵循既有能耗策略。XCTest 和夹具默认读者不连接真实客户端；
测试通过注入的合成读者验证时序。

`RecentSessionIndex` 的版本与字段不变：只保存路由身份、目录和活动时间。
名称不写入最近索引、关联缓存、日志或诊断，也不新增任何客户端配置。

## 操作与反馈

行内「在 Codex 打开」等客户端按钮明确执行导航，单击行仅选择。
键盘 Up/Down/Enter 仍限定在当前 Island 窗口，历史选择只遍历实际显示的记录。
未知来源保留详情/复制能力，不能导航。

`SessionActionController` 的反馈按相同的原生身份显示在相应行旁。
条目被隐藏或切换页面后，无法放回某行的反馈显示在列表标题下，避免失败信息丢失。
聊天、悬停和通知页面继续使用共享反馈。URI 被接受只表示打开请求已发送；
不能宣称 Codex 已显示该会话。

停靠与悬浮使用同一列表、标题与操作组件。悬浮的历史入口仍可固定面板，
即使当前没有会话也能查看记录。空列表、全部记录已在当前、关闭记录和
标题不可用都有明确文案。

## 验证

回归覆盖原生名称、实时改名与延迟读取、取消/清空、并行上限、读取参数、
客户端/来源身份、历史过滤、键盘选择和索引隐私；统一门禁为 `scripts/test.sh`。
人工核对两个原生展示形态的入口、详情和行内反馈，并另行核对安装副本。
构建目录使用 `.noindex`，旧安装副本压缩备份，避免再次出现多个搜索图标。

`Fixtures/mac-island-session-list.json` 提供两条当前和两条历史 Codex 合成记录，
包含同目录不同名称和缺失标题。设置 `MAC_ISLAND_FIXTURE_PATH` 后接入与索引存储
使用现有隔离规则；`storedCodexThreads` 仅为夹具元数据，不触发真实 RPC。
