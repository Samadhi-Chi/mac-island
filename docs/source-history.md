# Source history / 源码历史

## English

Mac Island is an independent derivative of
[Ping Island](https://github.com/erha19/ping-island). The original Apache 2.0
[LICENSE](../LICENSE.md), [NOTICE](../NOTICE), third-party licenses and attribution
are retained. This fresh Git baseline does not change their terms or claim sole
authorship of inherited work.

The source-publication review found private runtime evidence in earlier
development history. The maintainer chose to retain that entire repository,
including commits, issues, PRs and reviews, in the private
`Samadhi-Chi/mac-island-private-archive`. This independent `mac-island` repository
starts from the reviewed current source, without importing old Git objects,
references, runtime files, diagnostics or private imagery.

The imported baseline includes Mac Island's local, silent, monitor-only product
policy; supported client observation; shared session navigation and privacy;
onboarding, bilingual help and website; security repairs and isolated tests.
[The review record](public-readiness-2026-10-31.en.md) describes its coverage and
limits. Source availability is not a signed installer or App Store release.

Historical issue/PR links in retained documentation explicitly target the private
archive and require maintainer access. Their numbers do not identify issues/PRs
in this repository. Reusing the old repository name stops automatic old-name
redirects. New development uses fresh issues and PRs here.

Do not merge, fork-copy or push old archive history into this repository. Existing
clones of the old repository must point to the archive; use a fresh clone of this
repository for public development. Subsequent changes follow
[CONTRIBUTING.md](../CONTRIBUTING.md) and the final-head CI gate.

## 简体中文

Mac Island 基于 Ping Island 独立开发，保留原 Apache 2.0 许可、NOTICE、第三方许可
和署名。建立新的 Git 基线不会改变上游许可，也不代表继承代码由本项目独立创作。

公开检查发现早期开发历史含有私人运行资料。维护者选择把原仓库的全部提交、Issue、
PR 和审阅记录保存在私有 `mac-island-private-archive`，并从审查后的当前源码建立
独立的同名 `mac-island`。新仓库不导入旧 Git 对象、引用、运行数据、诊断或私人图片。

初始源码包含本机、静音、只读产品策略，客户端观察，会话导航与隐私控制，首次引导，
中英文帮助和网页，以及安全修复与隔离测试。检查范围和限制见
[公开前复核记录](public-readiness-2026-10-31.md)。源码公开不等于签名安装包或 App Store 发行。

历史文档中的旧 Issue/PR 链接指向私有归档，只有获授权的维护者能访问。旧编号不能用来
定位新仓库的条目；复用原仓库名后，旧名称不再自动重定向。新工作在本仓库重新建立 Issue/PR。

不要把私有归档的 Git 历史合并或推送回本仓库。旧 clone 应指向归档；公开开发使用新仓库
的全新 clone。后续修改继续遵守贡献指南及最终提交 CI 要求。
