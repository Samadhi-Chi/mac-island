## 界面验收

- 合成官方事件已覆盖 Claude Code CLI、Claude Desktop Code、OpenCode CLI/Desktop、Hermes CLI/Desktop。
- 卡片显示“项目名称 · Thread 名称”、最近提问、最新回复、服务商、模型、来源和最近活动。
- Claude 使用珊瑚色十二边线缓慢收缩释放；OpenCode 使用黑白灰 `【 】` 纯水平开合；Hermes 使用紫色短发头像、两枚无高光像素眼、无嘴结构和独立浮动耳机。
- 三类图标只在工作中动画，完成、空闲、错误和需处理时静止，并尊重“减少动态效果”。
- 收起态工作图标的连续画面存在像素差异，静止状态由单元测试固定验证。
- 权限事件仅显示“需处理”，界面不提供审批、回答或 Agent 控制。

## 隐私与网络边界

- 原始 Hook 参数、完整工具输出和凭据不写入 Bridge 日志、诊断或用量缓存。
- 最近提问、回复片段和活动明细只保留显示所需投影；屏幕内容只驻留内存。
- 产品策略关闭遥测、自动更新和声音。
- 不把“无遥测”表述为“绝对零网络”：启用且存在凭据时，Cursor 用量功能会访问 Cursor 官方用量接口；Claude 用量只读取本地 status-line 缓存，OpenCode/Hermes 未知额度显示 `—`。
