支持

先定位原因，
再处理问题。

这是社区维护的开发项目，目前没有付费支持或响应时间承诺。

看不到会话

  1. 确认只运行一份 Mac Island，避免安装版与开发预览混用。
  2. 打开集成设置，查看连接状态、最近成功读取和客户端版本。
  3. 确认客户端有活动会话。Codex 可使用“重新连接”重建 Island 的观察连接。
  4. Muse / Grok Bot 需要显式启用、辅助功能权限及受支持的当前界面；版本不支持时，不要把“看不到”当作任务停止。
  5. 仍有问题时，用合成数据记录复现步骤，再提交 Issue。

提交普通问题

请提供 Mac Island、macOS、客户端版本，顶部或悬浮模式，预期与实际行为，以及可以复现的最短步骤。截图前可使用临时隐藏，并检查其他应用有没有私人信息。

在 GitHub 提交问题 ↗

GitHub Issue 在仓库公开后对所有人可见。不要附上凭据、真实聊天记录或未经检查的诊断包。

报告安全问题

不要在公开 Issue 中披露漏洞细节、可利用步骤或凭据。请先打开仓库 Security 页面，使用已启用的私密漏洞报告入口；若没有该入口，请等待维护者建立私密渠道，不要改为公开提交。

下载与更新

当前没有正式签名安装包。正式候选需要 Developer ID 签名、Apple 公证、Gatekeeper 和安装/升级验收；完成后才会在本项目 Releases 公布。

不要使用上游安装包代替 Mac Island，也不要根据第三方重打包版本判断本项目的隐私与安全属性。当前应用不自动检查或下载更新。
