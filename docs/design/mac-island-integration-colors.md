# 本机集成设置配色

同一种状态或操作在各客户端使用同一种颜色。客户端通过原有图标和名称识别，
不再把品牌色用于安装状态、更新或配置按钮。

| 元素 | 规则 |
| --- | --- |
| 已安装 / 未安装 | 共用中性灰徽标；勾选 / 空心圆和文字区分状态 |
| 检查、配置、更新、安装、回滚、授权、重连 | 共用 macOS 系统强调色；保留原生按钮的加载、禁用与键盘行为 |
| 卸载 | 系统红色，声明为 destructive 操作 |
| 实际提示、更新失败 / 成功 | 警告用橙色标记，失败 / 成功图标用系统红 / 绿；说明正文用语义文字颜色 |

安装徽标只说明本机集成配置是否存在，不表示监控连接正常或客户端可用。
Hooks、自定义 Hooks 和 IDE 扩展共用 `IntegrationInstallationBadge`；本机按钮
共用 `HookManagementButton` 的默认强调色。颜色使用 AppKit 语义值，随系统
浅色、深色外观变化。保留状态文字与图标，不能仅靠颜色表达含义。

本次不改变安装判断、执行回调、备份或客户端配置。界面验收只观察和切换页面，
不得点击安装、更新、卸载或回滚来验证按钮样式。两种设置入口使用同一
`SettingsWindowView`；完整共享门禁及原生外观验收结果记录在
[迭代验证](../mac-island-iteration-validation.md)。
