Local information.
Your choice of visibility.

The app and this website have different data boundaries. A local app does not mean that visiting its website creates no server records.

What the app reads

Mac Island reads session state from supported clients through local hooks, observation interfaces, logs or databases. Native titles, conversations and progress details may be used in memory for display. Experimental Muse / Grok Bot sources read limited metadata from verified interfaces only after explicit opt-in and permission.

The app does not send messages, approve actions or start agent tasks. Current product policy disables telemetry, automatic updates and remote SSH services. Links and app-opening actions are handled by macOS and the destination app.

Connections and debugging

This monitor-only product disables Cursor account-token access and direct network quota requests. Codex observation uses a private pipe to a process owned by Island. Bridge debug logs are disabled by default and exclude content, paths and session IDs even when enabled. Recognized owned Bridge logs are removed when logging is disabled and pruned by retention when enabled. Legacy analytics, unrecognized files and flat logs in old custom directories require manual removal.

What appears on screen

  • Status only: client and generic status; native titles, Bot names, body text, paths and session IDs are hidden.
  • Titles: adds native session titles or Bot names; body text, activity labels, paths and IDs remain hidden.
  • Details: shows available local progress. Full paths and native IDs belong in explicitly opened detail views.

New installs default to titles. Existing installations preserve their prior detail behavior during migration. Temporary hiding affects Island only and restores the selected level. It neither covers other apps nor stops observation.

Local retention and removal

Recent routing metadata defaults to seven days and at most 200 entries. Options include 24 hours / 100 entries, this run only, or disabled. Records include client, working directory, native session ID and activity time, but no conversation text, prompts, replies or derived titles.

Clearing recent records does not delete the client’s history or separate association and usage caches. Old diagnostic exports are not automatically deleted. System backups, swap and storage owned by other clients are outside Mac Island’s control.

Permissions and diagnostics

You explicitly grant Accessibility permission for experimental sources and can revoke it in System Settings. Hook/plugin installation is an explicit action with local backups and atomic writes. A development build does not authorize installation or changes to client configuration.

User-triggered diagnostic summaries contain versions, fixed connection states and failure categories. They do not copy client configuration, logs, project paths, session titles, conversations or credentials. Exports stay local and are not sent automatically. Review an export before sharing it.

This website

GitHub Pages hosts this website. It uses local static assets, with no analytics, ads, cookies or browser storage added by this project. It does not connect to your clients or read your sessions.

GitHub records visitor IP addresses for hosting security. Following external links brings you under the destination service’s own privacy rules. See GitHub Pages data collection and the GitHub Privacy Statement.

Privacy questions

For ordinary questions, follow the support guide. Do not put private conversations, credentials, sensitive screenshots or raw diagnostics in public issues. For security reports, read the repository Security Policy first.
