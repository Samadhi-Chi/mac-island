Support

Understand the cause.
Then resolve the issue.

This is a community-maintained development project. Paid support and response-time guarantees are not provided.

No sessions are visible

  1. Confirm only one Mac Island instance is running. Avoid mixing the installed app with development previews.
  2. Open Integrations and check connection health, the last successful read and client versions.
  3. Confirm the client has an active session. For Codex, Reconnect rebuilds only Island’s observation connection.
  4. Muse / Grok Bot need explicit opt-in, Accessibility permission and a supported current interface. An unreadable interface does not mean the agent stopped.
  5. If the problem remains, record a minimal reproduction using synthetic data and open an issue.

Report an ordinary issue

Include the Mac Island, macOS and client versions; top-of-screen or floating mode; expected and actual behavior; and minimal reproduction steps. Before taking a screenshot, hide sensitive Island content and check other visible apps too.

Open a GitHub issue ↗

Public issues are visible to everyone. Never attach credentials, real chat histories or unreviewed diagnostic archives.

Report a security issue

Do not disclose vulnerability details, exploit steps or credentials in a public issue. Use the private vulnerability reporting entry on the repository Security page. If it is unavailable, wait for a private channel rather than posting confidential details publicly.

Open the Security page ↗

Downloads and updates

An official signed installer has not been released. Candidates require Developer ID signing, Apple notarization, Gatekeeper checks and installation/upgrade acceptance before they appear in this project’s Releases.

An upstream or third-party repackaged installer does not establish Mac Island’s privacy or security properties. The current app does not automatically check for or download updates.
